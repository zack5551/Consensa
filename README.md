# Consensa

**What Canada thinks happens next.** A free, no-stakes Canadian prediction and polling app in EN/FR. There's no money anywhere.

- Rules for contributors (people and Claude): [`CLAUDE.md`](CLAUDE.md)
- Plan and quality bar: [`docs/BUILD_PLAN.md`](docs/BUILD_PLAN.md)
- Legal guardrails: [`docs/legal/consensa-build-guardrails.md`](docs/legal/consensa-build-guardrails.md)
- Brand kit: [`brand/README.md`](brand/README.md)

```bash
pnpm install
pnpm dev        # http://localhost:3000 → /en or /fr
pnpm check      # typecheck + lint + unit tests
pnpm test:e2e   # Playwright + axe
```
